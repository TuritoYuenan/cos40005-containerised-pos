# Coding Conventions

## Naming Convention

Apply for Kotlin and SQL

| Component        | Casing           | Example                                           |
| ---------------- | ---------------- | ------------------------------------------------- |
| Classes          | PascalCase       | `User`, `SalesReport`, `MenuItem`                 |
| Methods          | camelCase        | `count`, `addItem`, `generateReport`              |
| Variables        | camelCase        | `items`, `intervalSeconds`                        |
| Constants        | UPPER_SNAKE_CASE | `DEFAULT_INTERVAL`, `SUPABASE_KEY`, `PRIVATE_KEY` |
| Database Table   | snake_case       | `users`, `sales_reports`, `menu_items`            |
| Database Columns | snake_case       | `id`, `branch_name`, `description`, `is_active`   |
